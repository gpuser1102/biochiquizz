# Biochiquiz

Web app di quiz per ripassare Biochimica, pensata per gli studenti del Corso di Laurea in Medicina e Chirurgia della Sapienza Università di Roma, Polo Pontino.

Si installa sulla schermata Home del telefono (iPhone e Android), funziona offline e salva i progressi solo sul dispositivo: nessun account, nessuna registrazione.

Creata da Gabriele Polonio, 2026.
